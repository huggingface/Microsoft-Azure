# Catalog

Hugging Face publishes a curated collection of open models to the `azure-huggingface` registry on Microsoft Foundry. Each one is packaged with the serving engine, context window, and accelerator it was validated on, so you deploy it on managed compute without assembling the stack yourself.

## Publisher highlights

The pages below highlight a few popular publishers and model families. They are curated starting points, not an exhaustive list of the Hugging Face collection. [Browse Microsoft Foundry](https://ai.azure.com/nextgen/goto/discover/models) for every model currently available.
