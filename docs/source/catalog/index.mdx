# Catalog

Hugging Face publishes a curated collection of open models to the `azure-huggingface` registry on Microsoft Foundry. Each one is packaged with the serving engine, optimized configuration, and accelerator it was validated on, so you deploy it on managed compute without assembling the stack yourself.
